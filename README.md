# Restaurant Website Master Template

A reusable, modern restaurant website template built with React.

This template is designed so a new restaurant website can be created by editing only a few files.

---

# Features

- Responsive Design
- SEO Friendly
- Online Menu
- Gallery
- Contact Form
- WhatsApp Integration
- Google Maps
- Fast Performance
- Easy Customization

---

# Project Structure
src/
 ├── components/
 ├── pages/
 ├── data/
 │    ├── site.js
 │    ├── content.js
 │    └── menu.js
 └── App.js

---

# Files to Edit for a New Client

## 1. site.js

Update:

- Restaurant Name
- Address
- Phone Number
- WhatsApp
- Google Maps
- Business Hours
- Social Links

---

## 2. content.js

Update:

- Hero Section
- About
- Reviews
- FAQs
- Homepage Content

---

## 3. menu.js

Update:

- Categories
- Menu Items
- Prices
- Descriptions

---

## 4. Images

Replace all demo images with the client's restaurant photos.

---

# Workflow

1. Copy the template.
2. Update site.js.
3. Update content.js.
4. Update menu.js.
5. Replace images.
6. Test locally.
7. Deploy.
8. Deliver to client.
